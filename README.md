# 秋招面试准备 Skill

根据岗位说明和个人经历，快速整理岗位匹配分析、自我介绍和模拟面试问题。

这是一个 AI 辅助制作的个人实践示例，重点展示如何把重复的面试准备组织为可复用流程。附带案例使用虚构输入，不代表真实个人经历或企业应用成果。

## 工作流程

岗位与经历输入 → 岗位要求拆解 → 经历匹配 → 回答草稿 → 事实检查 → 准备清单。

- **输入**：岗位 JD、简历片段或项目经历，可选准备时长和面试轮次。
- **输出**：岗位匹配表、约一分钟自我介绍、一段经历回答、三个模拟问题及准备顺序。
- **检查规则**：不编造经历和成果；区分个人职责与团队成果；缺失事实标记为待补充。

## 使用方法

查看 [SKILL.md](SKILL.md)，其中包含完整流程、调用示例和演示案例。

在支持自定义 Skill 的 AI 工具中，按该工具要求加载本文件夹。也可以将 SKILL.md 上传或粘贴到支持读取文本的 AI 对话中，作为任务指引使用。

示例请求：

```text
请按这份 Skill 的流程，帮我准备一次初面。
岗位 JD：[粘贴岗位说明]
个人经历：[粘贴脱敏后的经历]
准备时长：20 分钟
不要添加我没有提供的经历、数字或成果。
```
